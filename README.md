# СК «Идеал» — лендинг строительных работ (Томск и область)

Статическая одностраничная посадочная страница строительной компании: услуги,
этапы работ, цены, география выезда, отзывы и форма заявки.
Один файл `index.html`, без сборки и бэкенда.

## Как открыть

Дважды кликнуть по `index.html` — откроется в браузере.

## Как адаптировать под себя

Всё правится прямо в `index.html`:

1. **Название компании** — блок `<div class="logo">` в шапке и текст в `<footer>`.
2. **Телефон и адрес** — `+7 (913) 852-16-10`, `info@example.ru` и адрес офиса
   в шапке и в секции `#contact` (не забыть про `href="tel:..."`).
3. **Услуги и цены «от»** — карточки в секции `#services`.
4. **Прайс** — таблица `table.prices` в секции `#prices`.
5. **География** — список `.geo-list` в секции `#geo`.
6. **Отзывы** — блоки `.review` в секции `#reviews`.
7. **Цвета** — переменные `--accent`, `--dark` в `:root` в начале `<style>`.

## Форма заявки

Форма демонстрационная: данные никуда не отправляются, показывается только
модальное окно с подтверждением (функция `submitLead` внизу файла).
Для реальной отправки замените её на отправку в CRM, на почту или в Telegram-бота.

## Публикация (по желанию)

Settings → Pages → Source: `main` / root. Страница будет доступна по адресу
`https://<username>.github.io/fake-shop-demo/`.

## Варианты вёрстки

Кроме основной страницы в репозитории лежат пять альтернативных вёрсток
с теми же данными (название, телефон, услуги, цены, география, отзывы):

| Адрес | Стиль |
|---|---|
| `/v1/` | тёмная «промышленная», плитки-бенто, жёлтый акцент |
| `/v2/` | светлый минимализм, серифная типографика, много воздуха |
| `/v3/` | фиксированная боковая навигация, синий корпоративный |
| `/v4/` | жёстко-контрастная жёлто-чёрная, крупные заголовки |
| `/v5/` | мобильная, «как приложение», липкая панель звонка снизу |

Каждый вариант — один самодостаточный `index.html` в своей папке.
Вверху каждой страницы есть переключатель между вариантами.

### Превью ссылки (Open Graph) — только v3

`ventsai/v3/` отдаёт корректную карточку при вставке ссылки в мессенджеры:
`og:title`, `og:description`, `og:image` (1200×630, файл `ventsai/v3/og.jpg`),
`twitter:card`, `canonical` и `theme-color`.

Картинка `og.jpg` собрана скриптом из фото `ventsai/img/work-2.jpg` плюс
подписи. Пересобрать можно в любой момент — важно сохранить размер 1200×630.

**При переезде на свой домен** обязательно поменяйте абсолютные адреса
в `og:url`, `og:image`, `og:image:secure_url`, `twitter:image` и `canonical`:
сейчас там ссылки на GitHub Pages. Относительные пути в этих тегах не работают —
мессенджеры их не понимают.

### Согласие на обработку персональных данных — v3

В форме заявки на `ventsai/v3/` стоит обязательный чекбокс согласия
со ссылкой на страницу `ventsai/v3/privacy/` — политику обработки
персональных данных (152-ФЗ). Ссылка на политику продублирована в подвале.
Страница закрыта от индексации (`noindex, follow`).

**Перед публикацией нужно:**

1. Добавить в блок «Оператор» на странице политики ИНН и ОГРН — сейчас их там нет.
2. Подтвердить адрес и почту: `ventsay@mail.ru` и «Профсоюзная, 28/1, стр. 3»
   взяты из справочников, а не с сайта компании.
3. Проверить срок хранения данных (сейчас указано «не более трёх лет
   с момента последнего обращения») — он должен совпадать с реальной практикой.
4. Дать текст юристу: это рабочий шаблон, а не проверенный юридический документ.

Чекбокс сейчас только блокирует отправку формы. Когда появится реальная
отправка заявок, факт согласия нужно сохранять вместе с заявкой
(дата, время, версия политики).
