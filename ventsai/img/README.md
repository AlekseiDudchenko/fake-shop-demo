# Фотографии для сайтов ВентСай

Положите сюда файлы с этими именами — они автоматически подставятся
в галерею «Наши работы» на всех трёх вариантах (v1, v2, v3):

| Файл | Что показать |
|---|---|
| `work-1.jpg` | цех: изготовление воздуховодов |
| `work-2.jpg` | смонтированная приточно-вытяжная система |
| `work-3.jpg` | кухонный зонт из нержавейки |
| `work-4.jpg` | промышленный объект / аспирация |
| `work-5.jpg` | фасонные изделия, отводы и переходы |
| `work-6.jpg` | монтаж на объекте |

Пока файла нет — в галерее вместо фото показывается аккуратная заглушка
с подписью, вёрстка не ломается. Формат может быть любым, но тогда
поправьте расширение в `src` внутри блока `<section class="gal">`.
Оптимальный размер — примерно 1200×900 px, до 300 КБ на файл.
