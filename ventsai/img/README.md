# Фотографии для сайтов ВентСай-Томск

`work-1.jpg` … `work-8.jpg` — фотографии, которые выводятся в галерее «Наши работы»
на всех трёх вариантах.

| Файл | Что на фото |
|---|---|
| `work-1.jpg` | плазменный раскрой металла |
| `work-2.jpg` | вентиляционные изделия и фасонные детали |
| `work-3.jpg` | цех: изготовление воздуховодов |
| `work-4.jpg` | оцинкованные воздуховоды и решётки |
| `work-5.jpg` | смонтированная система вентиляции |
| `work-6.jpg` | вентиляция в помещении |
| `work-7.jpg` | фасадные кассеты на объекте |
| `work-8.jpg` | фасад и кровля из профлиста |

Файлы вырезаны из скриншотов сайта ventsay70.ru, поэтому разрешение
ограничено (около 800 px по ширине). Когда будут оригиналы — просто
замените файлы с теми же именами, вёрстку править не нужно.

Если файла нет, в галерее показывается заглушка с подписью — вёрстка не ломается.
